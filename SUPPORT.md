# Support

RebornForge is preparing its foundations. No operational platform, help desk, or response-time commitment is available yet.

Use repository issues for public documentation questions, corrections, and proposals within the approved phase. Check existing issues first, provide relevant sources, and omit personal or confidential information.

- Vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Conduct concerns: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- Rights corrections or removal requests: follow [rights guidance](docs/RIGHTS_AND_PRESERVATION.md).

The founder selected [GitHub issues](https://github.com/rebornforge/.github/issues/new/choose) for reports and removal requests. Issues are public; submit only necessary non-sensitive information. No confidential contact is currently designated. GitHub Discussions and other external support channels are not assumed to be active.
