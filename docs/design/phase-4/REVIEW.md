## Français

# Revue visuelle et vérification

## Revue réellement effectuée

Comparaison visuelle des planches générées avec le concept C approuvé : surfaces claires, bleu vif, texte marine, arrondis, cartes, navigation et adaptations empilées sur mobile. Les dix pages et deux planches d’états ont été inspectées à leur retour de génération.

Les premières versions ont introduit des écarts : noms/statuts non prévus, favoris et suivi hors MVP, discussion publique sur l’historique, patrimoine physique en modération et promesse de sauvegarde automatique. Des éditions d’images ont été demandées pour retirer ou corriger ces éléments. Seules les versions retenues sont intégrées au présent lot ; les premières générations ne font pas foi.

## Résultat de revue par groupe

| Groupe | Constat | Réserve |
| --- | --- | --- |
| M01 | Direction C, appels de découverte et contribution, avatars supprimés | Texte et illustration fictifs ; slogan plus discret sur mobile |
| M02/M03 | Catalogue lisible, filtres explicites, distinction droits/documentation, panneau mobile | Filtre Technologie corrigé ; les catégories détaillées restent illustratives, pas une taxonomie définitive |
| M04/M05 | Historique et initiative distincts, dates/droits inconnus et relation indépendante | M05 illustre une candidature incomplète non publiable, pas une fiche de production validée |
| M06/M07 | Sauvegarde manuelle, publication après revue, GitHub et profil privé minimal | Conservation des données et saisie après expiration à définir avant implémentation |
| M08/M09 | Suivi privé, actions selon état, échanges liés à une proposition | Une date d’échange d’exemple peut apparaître ; elle n’est pas une trace réelle |
| M10 | Revue de métadonnées numériques, motif et blocage de publication | Vérifier les permissions pour chaque usage ; documenter l’histoire ne vaut pas réutiliser le code |
| M11/M12 | Menu, chargement, vide, erreurs, retrait, doublon, confirmation, expiration, concurrence et issue publique | Petits panneaux servent de variations visuelles ; S10 et S15 restent spécifiés textuellement |

## Limites visuelles restantes

Les textes fins générés peuvent comporter des approximations ou coupes, surtout sur mobile. COPY_FR_EN.md donne les libellés de référence. Les petites cartes et onglets de M04/M05 nécessitent une vérification à taille de viewport avant validation définitive de leur comportement.

Les illustrations de projets sont décoratives et fictives, pas des captures d’archives. Les identités, dates, compteurs et sources dans les images ne doivent pas alimenter une base réelle.

M02 a été corrigée pour distinguer technologies et plateformes ; M03 pour aligner filtre actif et droits inconnus ; M12 pour montrer un champ vide réellement en erreur. Dans M10, le titre illustratif du troisième élément peut reprendre sa catégorie au lieu du nom Signal Desk : le référentiel des textes reste la source à retenir. Ces micro-libellés ne changent pas le périmètre.

## Vérifications techniques du livrable

Contrôles de format/dimensions/intégrité PNG, présence des fichiers et liens Markdown, couverture M01–M12/S01–S15 et organisation français/anglais. Les résultats exécutés sont rapportés dans la PR ; aucun résultat applicatif n’est déduit de ces contrôles.

## Non testé

Aucun backend, navigateur applicatif, navigation clavier exécutée, lecteur d’écran, formulaire transmis, authentification, contrôle réel de permissions, responsive exécuté ou mesure de contraste. Aucune conformité WCAG revendiquée. Les couleurs exactes, tailles et contrastes seront formalisés après validation graphique/prototype selon les phases prévues.

Anglais traduit dans les documents ; tous les écrans anglais et leurs débordements n’ont pas été dessinés ou testés. Les maquettes restent à examiner et corriger par le fondateur avant validation graphique et prototype. Aucun développement définitif commencé.

## English

# Visual review and verification

## Actual review

Visually compared generated boards with approved C: light surfaces, vivid blue, navy text, rounded cards, navigation and stacked mobile adaptations. Inspected ten pages and two state sheets as returned.

Initial generations introduced incorrect names/statuses, out-of-MVP bookmarks/following, public historical discussion, physical heritage in moderation and automatic-save promises. Image edits were requested to remove/correct these. Only retained versions belong to this package; initial generations are not authoritative.

## Findings by group

| Group | Finding | Reservation |
| --- | --- | --- |
| M01 | C direction, discovery/submission actions, avatars removed | Fictional illustration/copy; less prominent mobile slogan |
| M02/M03 | Readable catalogue, explicit filters, separate rights/documentation, mobile panel | Technology filter corrected; detailed category examples do not define a final taxonomy |
| M04/M05 | Distinct history/initiative, unknown dates/rights and independent relationship | M05 illustrates an incomplete unpublishable candidate, not an approved production record |
| M06/M07 | Manual saving, review before publication, GitHub/minimal private profile | Define retention and expired-session input behavior before implementation |
| M08/M09 | Private tracking, state-dependent actions, scoped exchanges | An illustrative exchange date may appear; no real audit event |
| M10 | Digital metadata review, reason and publication blocking | Assess rights for each use; documenting history is not code reuse |
| M11/M12 | Menu/loading/empty/error/withdrawal/duplicate/confirmation/expiry/concurrency/public issue | Mini-panels are visual variants; S10/S15 remain text-specified |

## Remaining visual limits

Fine generated text may be imperfect/clipped, especially mobile. COPY_FR_EN.md is authoritative. M04/M05 small cards/tabs need viewport-size checks before definitive behavior approval.

Project illustrations are fictional decoration, not archival screenshots. Image identities, dates, counts and sources must not populate a real database.

M02 was corrected to separate technologies/platforms; M03 to align active filters/unknown rights; M12 to show an actually empty invalid field. M10's third illustrative item may show its category instead of Signal Desk: source copy remains authoritative. Such microcopy does not change scope.

## Deliverable checks

PNG format/dimension/integrity, file/link presence, M01–M12/S01–S15 coverage and French/English organization. The PR reports executed results; no application findings inferred.

## Not tested

No backend, application browser, executed keyboard/screen-reader/form/authentication/permission checks, responsive execution or contrast measurement. No WCAG compliance claimed. Exact color/size/contrast specifications follow graphical/prototype approval under the agreed phases.

English translated in documents; full English screens/overflow not drawn or tested. Founder review/correction and graphical approval precede prototyping. No final application development started.
